a ideia era criar um visualizador geometrico das moleculas, mas o foco se desviou para reimplementar o código de https://github.com/renatolois/moleculae-xr, reescrevendo a engine em python para facilitar exportar para outros sistemas operacionais e também devido à facilidade de controle de versão (principalmente do opencv), além de algumas correções na classe vision, transform, e adicionar a classe Atom com a implementação de uma elestrosfera, houve uso de IA para gerar o código das funções de teste (como na criação de um grid para o chão e também para entender um pouco dos cálculos feitos na classe Vision), e também houve uso de IA para reescrever a função main de forma mais organizada devido ao prazo de entrega do projeto e para o menu de escolha entre math e chemistry.
